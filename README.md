# El Sazón de la Abuela

Proyecto web estático listo para abrir en Visual Studio Code.

## Cómo ejecutarlo
1. Abre la carpeta `sazon_abuelita` en VS Code.
2. Abre `index.html` directamente en tu navegador, o instala la extensión **Live Server**.
3. Con Live Server, haz clic derecho en `index.html` > **Open with Live Server**.

## Estructura
- `index.html`: estructura principal.
- `css/styles.css`: estilos y responsive.
- `js/main.js`: menú móvil, filtros de platos y envío de reserva a WhatsApp.
- `assets/img/`: imágenes extraídas del diseño exportado.

## Personalización rápida
- Número de WhatsApp: cambia `573001234567` en `js/main.js`.
- Dirección: edita la sección `#ubicacion` en `index.html`.
- Precios/platos: edita las tarjetas dentro de `.menu-grid`.

## Nota
Las imágenes usadas fueron recuperadas del PDF exportado del diseño original para mantener la apariencia lo más cercana posible.
